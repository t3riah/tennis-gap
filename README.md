# Tennis Gap

Player stats and match predictions from real charted-match data - a serve-first model with first/second serve splits, return splits, and double faults.

Open the site, pick a tour and surface, and either look up one or two players or run a head-to-head prediction. Profiles come from Jeff Sackmann's Match Charting Project, recency-weighted and shrunk toward tour averages, with freshness (matches charted + latest date) shown for every player.
